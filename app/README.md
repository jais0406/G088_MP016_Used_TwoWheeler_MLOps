# app/ — Prediction API

FastAPI service that predicts `resale_thousand_rs` (resale price in thousand
rupees) for a used two-wheeler, using the champion model in `models/model.joblib`.

| File | Purpose |
|---|---|
| `main.py` | `GET /health`, `POST /predict`; loads the model once at startup; logs every prediction and every rejected request |
| `schemas.py` | Request/response schemas, including the client's two rules |
| `logging_config.py` | JSON formatter: one JSON line per log record, written to stdout |

## Endpoints

| Method | Path | Returns |
|---|---|---|
| `GET` | `/health` | `{"status": "ok", "model_loaded": true, "model_version": "champion"}` |
| `POST` | `/predict` | `{"resale_thousand_rs": 115.88, "model_version": "champion"}` |
| `GET` | `/docs` | Interactive Swagger UI (generated by FastAPI) |

## Request body

Exactly these eight fields. Any other field (for example the leaking
`final_price_from_rc_transfer`) is rejected.

| Field | Type | Rule |
|---|---|---|
| `age_years` | number | `0 <= age_years <= 25` (**client rule 1**) |
| `km_driven` | number | `>= 0` |
| `engine_cc` | number | `>= 50` (**client rule 2**) |
| `owners` | integer | `>= 0` |
| `service_records` | integer | `>= 0` |
| `accidents` | integer | `>= 0` (so the `-999` sentinel is rejected) |
| `brand_tier` | text | `budget`, `mid` or `premium` |
| `city_zone` | text | `North`, `South` or `Central` |

The rules are pydantic `Field(..., ge=..., le=...)` constraints, so a bad
request gets **422** and never reaches the model.

## Status codes

| Code | When |
|---|---|
| 200 | Prediction made |
| 422 | Missing, extra or out-of-range field |
| 500 | The model raised an error while predicting |
| 503 | No model file was found at startup |

## Logging

Every log line is a JSON object on stdout, for example:

```json
{"time": "...", "level": "INFO", "logger": "mp016-api", "message": "prediction",
 "event": "prediction", "features": {...}, "prediction": 115.876,
 "model_version": "champion", "latency_ms": 1.2}
```

Rejected requests are logged with `"event": "rejected"` and only the names of
the bad fields and the error types, never the values sent. No personal
details are logged.

## Configuration

| Variable | Default | Meaning |
|---|---|---|
| `MODEL_PATH` | `models/model.joblib` | Model file loaded at startup |
| `MODEL_VERSION` | `champion` | Label returned in responses and logs |

## Run

From the project root:

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

or with Docker:

```bash
docker build -t mp016-api:1.0 .
docker run --rm -p 8000:8000 mp016-api:1.0
```

## Example

```bash
curl -X POST localhost:8000/predict -H 'content-type: application/json' \
  -d '{"age_years":5,"km_driven":30000,"engine_cc":150,"owners":1,
       "service_records":6,"accidents":0,"brand_tier":"mid","city_zone":"North"}'
```
